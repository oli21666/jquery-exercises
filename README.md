# Ćwiczenia jQuery

[English version below](#jquery-exercises)

Zestaw sześciu prostych, interaktywnych ćwiczeń z HTML, CSS i jQuery. Każde zadanie znajduje się w osobnym pliku HTML i pokazuje inny sposób reagowania strony na działania użytkownika.

## Opis repozytorium

Projekt zawiera przykłady obsługi zdarzeń i efektów jQuery: rozwijane treści, reakcję na najechanie kursorem, zmianę obrazu, dynamiczne modyfikowanie listy, odczytywanie wartości formularza oraz prostą galerię. Wspólne style znajdują się w `style.css`, a biblioteka jQuery jest dołączona lokalnie.

## Zadania

| Plik | Opis |
| --- | --- |
| `zad1.html` | Rozwijanie i zwijanie treści po kliknięciu przycisku. |
| `zad2.html` | Pokazywanie i ukrywanie treści po najechaniu kursorem. |
| `zad3.html` | Zmiana obrazu po najechaniu kursorem. |
| `zad4.html` | Dodawanie elementów do listy i usuwanie ostatniego elementu. |
| `zad5.html` | Wyświetlanie wartości wpisanej w polu tekstowym, wybranej opcji i zaznaczonych pól. |
| `zad6.html` | Prosta galeria, w której kliknięty obraz zostaje powiększony. |

## Uruchomienie

Nie jest potrzebna instalacja zależności ani kompilacja. Otwórz wybrany plik `zad1.html`–`zad6.html` bezpośrednio w przeglądarce. Możesz też uruchomić lokalny serwer HTTP w katalogu projektu i otworzyć odpowiednią stronę przez serwer.

Pliki korzystają ze wspólnego arkusza `style.css` oraz lokalnej kopii jQuery `jquery-1.11.3.js`. Zadanie 3 pobiera obrazy z zewnętrznych adresów, dlatego do jego pełnego działania potrzebne jest połączenie z internetem. Zadanie 6 używa obrazów z katalogu `assets`.

## Technologie

- HTML
- CSS
- JavaScript
- jQuery 1.11.3

# jQuery Exercises

[Wersja polska powyżej](#ćwiczenia-jquery)

A collection of six simple, interactive exercises using HTML, CSS, and jQuery. Each exercise is in a separate HTML file and demonstrates a different way for a webpage to respond to user actions.

## Repository overview

The project includes examples of jQuery event handling and effects: expandable content, hover interactions, image swapping, dynamic list manipulation, reading form values, and a simple gallery. Shared styles are defined in `style.css`, and the jQuery library is included locally.

## Exercises

| File | Description |
| --- | --- |
| `zad1.html` | Expand and collapse content by clicking a button. |
| `zad2.html` | Show and hide content on hover. |
| `zad3.html` | Change an image on hover. |
| `zad4.html` | Add items to a list and remove the last item. |
| `zad5.html` | Display the text input, selected option, and checked values. |
| `zad6.html` | A simple gallery that enlarges the image you click. |

## Getting started

No dependency installation or build step is required. Open any file from `zad1.html` to `zad6.html` directly in a web browser. Alternatively, start a local HTTP server in the project directory and open the relevant page through the server.

The pages use the shared `style.css` stylesheet and the local copy of jQuery, `jquery-1.11.3.js`. Exercise 3 loads images from external URLs, so an internet connection is required for it to work fully. Exercise 6 uses images from the `assets` directory.

## Technologies

- HTML
- CSS
- JavaScript
- jQuery 1.11.3
